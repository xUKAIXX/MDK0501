## Что где лежит

Всё собрано в двух папках:

| Папка | Содержимое |
| --- | --- |
| `reports/сделано/` | только готовые работы: 13 отчётов `.docx` и 30 схем `.vsdx` для Visio |
| `reports/отчёт/` | только картинки `.png`, по которым видно, что нарисовано (30 схем + 2 листа предпросмотра) |

Лишнего нет: ни PDF, ни SVG, ни архивов — только DOCX, Visio и PNG.

## Схемы

Все изображения — `reports/отчёт/*.png` (200 dpi). Для каждой работы пара
«пример методички — свой вариант»; схемы построены из блоков нотации
(IDEF0, DFD, IDEF3, IDEF1X, UML), без произвольных фигур.

Листы предпросмотра: `предпросмотр_1_примеры.png` (12 схем-примеров) и
`предпросмотр_2_вариант.png` (14 схем варианта) — все схемы сразу на одной
картинке с подписями.

## Схемы для Visio

`reports/сделано/<имя>.vsdx` — не картинка, а набор фигур Visio:

* прямоугольники, скругления заданы ячейкой `Rounding` (скругляет сам Visio);
* эллипсы прецедентов — родная фигура `Ellipse`, гладкая в любом масштабе;
* линии и ломаные — пути с наконечником `EndArrow`, стрелку рисует Visio;
* подписи — текстовые шейпы Arial нужного кегля, с начертанием и подложкой.

Оформление прописано в каждой фигуре, наследование темы отключено, поэтому
схема выглядит одинаково в Visio 2016/2019/2021 и в Visio в браузере.
Файлы собирает `tools/vsdx_export.py` на основе пустого документа Visio из
пакета `vsdxkit`. Ограничение: фигуры не связаны динамическими коннекторами —
при перетаскивании блока линия за ним не тянется.

## Как пересобрать

```bash
python3 tools/fig_idef0.py     # IDEF0
python3 tools/fig_dfd.py       # DFD
python3 tools/fig_idef3.py     # IDEF3
python3 tools/fig_model.py     # оргструктура, IDEF1X
python3 tools/fig_uml.py       # UML
python3 tools/preview_sheets.py  # листы предпросмотра
cd tools && python3 -c "
import rep_a, rep_b, rep_c, inspect
for m in (rep_a, rep_b, rep_c):
    for name, f in inspect.getmembers(m, inspect.isfunction):
        if f.__module__ == m.__name__ and not name.startswith('_'):
            f()
"                               # сборка всех 13 DOCX
```

Сначала рисунки (PNG в `reports/отчёт` и `.vsdx` в `reports/сделано`), затем
DOCX — отчёты вставляют готовые PNG. Ширина любой картинки при вставке
ограничена 16,2 см — это ширина полосы набора при полях 3/1,5/2/2 см.

`tools/notation.py` — библиотека нотаций, `tools/docx_report.py` — сборка
документа (Times New Roman 14, интервал 1,5, поля 3/1,5/2/2 см, нумерация
страниц).
